# 🏪 Esnaf AI

> **Küçük İşletmeler İçin Konuşarak Uygulama Üreten Yapay Zeka Platformu**
> 2026 AI-Agent & AI-Coder Trendi Projesi

Esnaf AI, kodlama veya teknik bilgi gerektirmeden, sadece yapay zeka ile konuşarak veya yazışarak küçük işletmelerin (esnafların) kendi mobil uygulamalarını/dijital sistemlerini anında oluşturabildiği devrimsel bir platformdur.

## 🌟 Öne Çıkan Özellikler

- **🤖 AI App Generator:** Sadece *"Randevu sistemi istiyorum"* veya *"Sadakat kartı oluştur"* diyerek saniyeler içinde çalışan bir arayüz üretme.
- **📱 Canlı Önizleme (Live Preview):** Yapay zeka kodu yazarken, sağ taraftaki interaktif telefon ekranında anlık olarak uygulamanın belirmesi ve kullanılabilmesi.
- **🇹🇷 Hiper-Yerel Konsept:** Global piyasadaki "Yazılımcılar için AI" (Devin, Cursor vb.) vizyonunu alıp, Türkiye'deki geleneksel esnaf (berber, çay ocağı, lokanta) kültürüne uyarlama.
- **⚡ Anında Dağıtım (Simülasyon):** Üretilen dijital menü, sadakat kartı veya randevu sisteminin doğrudan müşteriler tarafından (QR kod ile vb.) kullanılabilecek sadelikte olması.

## 🛠️ Teknoloji Stack

- **Framework:** Next.js 15 (React 19)
- **Dil:** TypeScript
- **Stil:** Tailwind CSS + Vanilla CSS (Custom Design System & Phone Mockup)
- **State Yönetimi:** Zustand (Persistent Store)
- **İkonlar:** Lucide React
- **Bildirimler:** Sonner

## 🚀 Kurulum ve Çalıştırma

Proje bağımlılıklarını yükleyin:
```bash
npm install
```

Geliştirme sunucusunu başlatın:
```bash
npm run dev
```

Tarayıcınızda `http://localhost:3000` adresine gidin.

## 🎭 Demo Modu (Sunum İçin)

Proje, gerçek API anahtarlarına ihtiyaç duymadan sınıfta akıcı bir sunum yapabilmeniz için **simüle edilmiş bir AI** ile gelmektedir.
Arayüzden "Sadakat Kartı", "Randevu Sistemi" veya "Dijital Menü" isteklerinde bulunarak, sağdaki telefon ekranında uygulamanın canlı olarak oluştuğunu gösterebilirsiniz.
